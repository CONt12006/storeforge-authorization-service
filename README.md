# storeforge-authorization-service
Микросервис авторизации на Go для централизованной проверки прав доступа пользователей. Поддерживает RBAC и ABAC-политики, проверку владения ресурсами, приоритет запрещающих правил, хранение ролей и разрешений в PostgreSQL, кэширование effective permissions в Redis и интеграцию с C++ Session Service для проверки активных пользовательских сессий.
